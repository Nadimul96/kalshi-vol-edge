Everything else in this dashboard works without one. To see positions and fills here, and to reconcile them live:

  1. Create a free account on Kalshi's demo exchange (paper money) and generate an API key in its settings. The private key downloads once as a PEM file.
  2. Copy .env.example to .env and set KALSHI_API_KEY_ID and KALSHI_PRIVATE_KEY_PATH. KALSHI_ENVIRONMENT defaults to demo.
  3. Restart with uv run kve dashboard. Run uv run kve doctor to check the setup.

Placing orders stays in the CLI: kve order uses the demo exchange unless you pass --live and confirm.
